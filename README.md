# Findring

Findring 是一个 Windows 本地任务协调工具：配置协调代理和执行 Harness，讨论目标、确认计划，再按工作包推进任务。

[下载最新版本](https://github.com/Lchen-mo/findring-releases/releases/latest)

## 开始使用

1. 下载 Release 中的 Windows x64 安装包并安装。
2. 按应用内教程配置所需官方 Harness CLI，登录自己的受支持账号，或填写自己的 API 连接。
3. 新建对话，选择协调代理与工作目录，讨论目标并确认执行计划。

安装包内含 Node 运行环境；缺少 WebView2 时安装器需要联网安装。不要向他人发送密钥、登录数据或整个工作目录。

## 试用边界

当前为早期预览版，完整跨 Harness 任务交付仍在验证。模型输出需要核对；程序检查通过不代表科研结论已被证明。未知执行状态应先核对，不自动重发。
